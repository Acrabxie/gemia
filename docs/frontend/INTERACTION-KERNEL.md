# Lumeri 视频微调交互内核

**版本** v0.1 · 2026-08-05
**地位** `DESIGN-SPEC.md` 第 12 章的强制实现细则。冲突时以 `DESIGN-SPEC.md` 为准。
**目标** 让创作者直接在画面和时间线上选中、移动、缩放、旋转、定位和修剪视频素材，并能用精确数值完成同一操作。

## 1. 单一编辑状态

1. v0.1 同时只允许一个主选择。选择由稳定引用描述：`authority`（timeline 或 lumenframe）、`entity_id`、`revision`，界面不得显示内部 ID。
2. 点击时间线 clip 后，预览必须显示同一对象的选框；点击预览对象后，时间线必须选择并滚动到同一 clip。对象旁微调条和“属性”模块读取同一份状态，禁止各自缓存第二份属性值。
3. `Esc` 先取消当前手势，再清除选择；切换 Project、删除对象或权威状态不再包含该对象时自动清除选择。
4. 选择不等于播放。移动 playhead 只改变时间上下文，不擅自改选对象；当前选择在该帧不可见时保留选择并显示“当前帧不可见”。

## 2. 双形态属性入口

1. 选择可编辑对象后，在目标附近出现紧凑微调条。预览上下文只放 `X / Y / 缩放 / 旋转`；时间线上下文只放 `开始 / 时长 / 入点 / 出点`。每次最多显示 4–6 个值。
2. 微调条应贴近目标但不得覆盖选框、trim 手柄或 playhead；空间不足时自动翻转到目标另一侧。它没有独立标题、说明卡或二次确认。
3. 微调条的展开动作打开可拖动、可缩放、可关闭的“属性”工作区模块。模块显示空间和时间两组完整字段；关闭模块不清除选择。
4. 数字输入使用等宽 `tabular-nums`。`Enter` 提交一个原子操作，`Esc` 恢复编辑前值；仅在值合法且确实改变时，失焦才提交。

## 3. 空间微调

1. 画布坐标以左上角为 `(0, 0)`；`X / Y` 表示对象变换后包围盒中心点的绝对画布像素坐标。v0.1 锚点固定为中心，缩放固定为等比。
2. 选框四角是等比缩放手柄；选框上方是旋转手柄；选框内部拖动对象。高频拖动零动画，指针移动只更新本地预览，`pointerup` 只提交一次原子操作。
3. 移动：方向键 `1 px`，`Shift + 方向键` 为 `10 px`。拖动时 `Shift` 锁定主轴；`Option/Alt` 临时关闭吸附。
4. 缩放：数字步进 `1%`，`Shift` 为 `10%`；不得小于 `1%`。旋转：步进 `1°`，`Shift` 为 `15°`；拖动时 `Shift` 吸附到 `15°` 倍数。
5. 默认吸附画布四边、中线以及其他可见对象的边与中心；命中阈值按屏幕距离 `6 px`，不随画布缩放改变。吸附线仅在命中期间显示，提交后立即消失。
6. 空间操作必须进入最终导出。若某对象类型暂不支持真实导出，界面必须只读并说明原因，禁止让用户调整后在成片中静默丢失。

## 4. 时间微调

1. 可视时间值全部吸附到当前 Project 的帧率；界面不产生亚帧视觉边界。方向键微移 `1 帧`，`Shift + 方向键` 为 `10 帧`。
2. clip 本体拖动改变开始时间；左右手柄改变入点/出点。拖动期间只更新本地预览，释放时提交一个操作。需要两条底层补丁的兼容操作必须由后端作为一个用户动作串行执行，不能在界面制造半完成状态。
3. 时间码格式为 `HH:MM:SS:FF`，同时接受纯帧数输入。开始时间不得小于 0；时长不得小于 1 帧；入点不得小于 0；出点必须大于入点且不得超出已知源时长。
4. 吸附对象为 playhead、marker、其他 clip 的首尾和整秒边界，阈值按屏幕距离 `8 px`；`Option/Alt` 临时关闭吸附。

## 5. 提交、协作与冲突

1. 每个用户手势必须携带当前 Project revision 与唯一 `client_op_id`；重复提交同一个 ID 必须幂等。成功响应必须返回权威后状态并立即校正本地预览。
2. Agent 工作期间，选择、播放和本地手势保持可用；提交通过 Project 串行编辑循环在安全边界执行。一个对象同一时刻只允许一个待提交操作，后续手势等待权威结果。
3. revision 冲突时禁止静默覆盖。界面回读最新状态、撤销本地预览，并用创作者语言提示“画面刚被更新，已同步最新版本，请再试一次”。
4. 非冲突失败同样回读权威状态。失败文案说明哪个动作没有生效，不显示错误枚举、内部 ID 或堆栈。
5. 直接操控的感知反馈目标是 `100 ms` 内；网络提交可更慢，但不得冻结画布或时间线滚动。

## 6. 撤销、重做与可访问性

1. `⌘/Ctrl + Z` 撤销最近一次用户或 Agent 的权威 Project 编辑；`⌘/Ctrl + Shift + Z` 重做。一次拖动、一次数字提交或一次键盘微移只占一个历史步。
2. 撤销/重做按钮的可用态来自后端历史，不凭前端猜测；新的编辑发生后清空相应重做分支。
3. 所有手柄指针目标至少 `24 × 24 px`，视觉可以更小；手柄有可读 `aria-label`，选框可通过键盘完整操作。
4. 选中不能只靠颜色：选框同时使用轮廓、角点和可读对象名。焦点 ring 与选择 ring 不互相覆盖。
5. `prefers-reduced-motion` 下不播放过渡；本内核的高频编辑本来就不使用位移动画。

## 7. v0.1 边界

- 本期实现：单选、预览/时间线联动、移动、等比缩放、连续旋转、帧级时间微调、双形态属性入口、串行提交、冲突回读、撤销/重做。
- 本期只定义不实现：多选与编组、任意锚点、非等比缩放、裁剪/蒙版、贝塞尔路径、关键帧曲线、磁性/波纹模式切换、跨 Project 复制。
- 普通 timeline clip 与 LumenFrame layer 可保留各自持久化结构，但必须通过同一前端选择/属性适配器呈现；不得为迁移界面而批量改写旧 Project。
